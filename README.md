# sph-zstd++

A header-only C++23 implementation of [Zstandard](https://facebook.github.io/zstd/) with compile-time compression settings and callback-driven streaming. The bundled reference implementation is used to check compressed bytes and measure performance at matching levels.

[Get started](#get-started) · [Build and test](#build-and-test) · [Run a benchmark](#run-a-benchmark) · [Performance](#performance) · [Windows performance](#native-windows-decompression) · [Development progress](PERFORMANCE_PLAN.md)

## What it supports

The library provides streaming compression and decompression, Huffman and FSE entropy coding, checksums, concatenated and skippable frames, and match parsing from fast through binary-tree strategies. It is an active port; dictionary and multithreaded modes are still missing.

The current benchmark matrix checks byte-for-byte compressed output at levels 1–22 on five deterministic inputs. The acceptance tests also check decoding in both directions.

## Get started

Add `include` to your C++23 include path, or link the header-only `sph::zstdpp` CMake target. Output is delivered to a callback whose span remains valid for that invocation. Call `finish()` explicitly; destructors do not emit or validate output.

For a CMake project, place this repository at `external/zstdpp` and link your application:

```cmake
add_subdirectory(external/zstdpp)
target_link_libraries(your_app PRIVATE sph::zstdpp)
```

```cpp
#include <sph/zstd++/zstd.h>

#include <cstdint>
#include <span>
#include <vector>

std::vector<std::uint8_t> compressed;
auto compressor = sph::zstd::zstd_compress{
    [&compressed](std::span<std::uint8_t const> bytes) {
        compressed.insert(compressed.end(), bytes.begin(), bytes.end());
    }};

std::vector<std::uint8_t> input{/* ... */};
compressor.update(input);
compressor.finish();

std::vector<std::uint8_t> restored;
auto decompressor = sph::zstd::zstd_decompress{
    [&restored](std::span<std::uint8_t const> bytes) {
        restored.insert(restored.end(), bytes.begin(), bytes.end());
    }};
decompressor.update(compressed);
decompressor.finish();
```

Compression parameters can be fixed at compile time. The helper preserves the callback's concrete type for inlining:

```cpp
constexpr auto settings = [] {
    auto value = sph::zstd::compression_parameters{};
    value.checksum = true;
    value.window_log = 20;
    return value;
}();

auto compressor = sph::zstd::make_zstd_compress<settings>(callback);
```

For a complete borrowed input, `compress_frame(span)` avoids copying it into streaming history. The streams also provide `update`, `flush` (compression), `reset`, status, byte counters, and parsed frame information.

## Build and test

Use a C++23 compiler and CMake 3.28 or newer.

```text
cmake -S . -B out/build -DSPH_ZSTDPP_BUILD_TESTS=ON
cmake --build out/build
ctest --test-dir out/build --output-on-failure
```

For the reference-byte acceptance suite, use `msvc-acceptance`, `clang-acceptance`, or `gcc-acceptance`:

```text
cmake --preset msvc-acceptance
cmake --build --preset msvc-acceptance
ctest --preset msvc-acceptance
```

The tests compare resolved compression parameters and compressed bytes, and check decoding in both directions. The public library target itself does not link reference zstd.

## Run a benchmark

The `zstdpp_pair` tool compares optimized C++ and reference workers at the same compression level on your input. It checks byte-for-byte compressed output and verifies that both decoders recover the original input before reporting performance.

For Windows, run these commands from a Visual Studio x64 developer shell:

```text
cmake --preset msvc-release-eval
cmake --build --preset msvc-pair
out/build/msvc-release-eval/eval/bin/zstdpp_pair.exe --level 3 --input path/to/file --iterations 1000 --trials 6
```

For GCC, use the `gcc-release-eval` configure preset and `gcc-pair` build preset, then run `out/build/gcc-release-eval/eval/bin/zstdpp_pair`. The tables below use 1 MiB inputs. See the [benchmark report](BENCHMARKS.md) for measurement conditions and reproduction details.
